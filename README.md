# 📊 Projeto Base — Análise de Dados de Vendas

Projeto desenvolvido durante um desafio da **DIO**, com foco na consolidação, organização e análise de dados de vendas provenientes de diferentes marketplaces.

## 🎯 Objetivo

Transformar dados de vendas em informações relevantes para compreender:

* os produtos mais vendidos em cada país;
* o comportamento das vendas por mercado;
* diferenças no perfil dos clientes;
* possíveis oportunidades para planejamento de estoque, transporte e logística.

## 📂 Dados

Foram utilizadas três bases fictícias, fornecidas pela DIO para fins educacionais:

* 🛒 AliExpress
* 🛍️ Etsy
* 🏪 Shopee

As bases originais estão em `data/raw_data/` e os dados consolidados e organizados estão em `data/process_data/`.

## 🤖 Análise

Após a consolidação dos dados, foram utilizados **prompts no ChatGPT** para apoiar a análise e a geração de insights.

Os prompts, respostas e análises detalhadas estão documentados em:

👉 [`prompts/readme.md`]
